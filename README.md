# Insertion Sort in C++

This repository contains a simple implementation of the **Insertion Sort algorithm** using C++.

## 📌 About the Project

Insertion Sort is a sorting algorithm that builds the sorted array one element at a time. It compares each element with the previous elements and places it in the correct position.

## 💻 Code Features

- Implemented using C++.
- Sorts an array in ascending order.
- Uses loops and conditional statements.
- Beginner-friendly implementation.
- Prints the sorted array.

## 🛠️ Technologies Used

- **Language:** C++
- **Concepts:** Arrays, Loops, Functions, Sorting Algorithms

## 📥 Example

**Input:**
```cpp
arr[] = {5, 4, 1, 3, 2};
```

**Output:**
```text
1 2 3 4 5
```

## ⏱️ Time and Space Complexity

- **Best Case:** O(n) for an already sorted array.
- **Average Case:** O(n²).
- **Worst Case:** O(n²).
- **Space Complexity:** O(1) auxiliary space.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Compile the C++ file using a C++ compiler.
4. Run the executable to see the sorted array.
